## GRUB 的 Katifetch

Katifetch 还可以作为自定义启动菜单项存在于 GRUB 中。

此版本直接从 GRUB 菜单显示 Katifetch 风格的系统概述，在启动操作系统之前充当可视的复活节彩蛋。

---

## ⚠️ 重要提示

GRUB 无法获取实时系统数据。
显示的所有信息都是静态的或有意标记为“未知”。

---

## ✨ 特点

- GRUB 内的 Katifetch 风格布局
- ASCII 标志和格式化系统概述
- 安全：不启动操作系统
- 自动返回GRUB菜单
- 适用于 BIOS 和 UEFI 系统

---

## 📦 安装（GRUB）

### 打开 GRUB 自定义条目文件

```bash
sudo nano /etc/grub.d/40_custom
```

## 将以下菜单项粘贴到文件末尾
>（在注释下方，不修改标题）：
```bash
menuentry "Katifetch" {
    clear
    echo ""
    echo ",,                                           Katifetch"
```
